👟 SneakWear Studio

SneakWear Studio es una plataforma web responsive para explorar, personalizar y comprar zapatillas. El proyecto busca ofrecer una experiencia sencilla e interactiva en la que los usuarios puedan elegir un modelo, configurar sus características, revisar el resultado y consultar sus pedidos.

Desarrollado por el Grupo 3 como parte del curso HCI for UX Design.

✨ Funcionalidades principales
- Exploración de productos: consulta modelos de zapatillas, precios, disponibilidad y valoraciones.
- Personalización: selección de colores y materiales, además de opciones para incorporar textos o imágenes.
- Vista previa: revisión del diseño con controles de visualización y rotación.
- Tallas: selección de tallas y consulta de una guía de medidas.
- Favoritos y diseños guardados: conserva diseños y productos de interés en el navegador.
- Carrito de compras: revisa los productos y las características seleccionadas antes de continuar.
- Reseñas: consulta las valoraciones y opiniones disponibles.
- Seguimiento: visualiza las etapas previstas para el estado del pedido.
Importante: esta versión es un prototipo académico de front-end. Algunas funciones, como la disponibilidad de stock, el pago y el seguimiento, utilizan datos de demostración. No se realizan transacciones comerciales reales ni se conecta con un servicio de pago o logística.

▶️ Cómo ejecutar el proyecto localmente
1. Descarga el repositorio o utiliza la opción Code → Download ZIP en GitHub.
2. Extrae los archivos, si descargaste el ZIP.
3. Verifica que index.html, styles.css, script.js y sneaker-studio.jpg permanezcan en la misma carpeta.
4. Abre index.html con un navegador actualizado.
No se requiere instalar dependencias ni ejecutar un proceso de compilación para esta versión estática.
🌐 Publicación con GitHub Pages
El proyecto puede publicarse desde GitHub Pages:
1. Abre el repositorio en GitHub y entra en Settings → Pages.
2. En Build and deployment, selecciona Deploy from a branch.
3. Selecciona la rama main y la carpeta / (root).
4. Guarda los cambios y espera a que GitHub genere la dirección pública.
5. Comprueba que la página cargue correctamente y que sus recursos se visualicen.
URL del proyecto: Agregar aquí la URL pública de GitHub Pages cuando esté desplegado.
📱 Diseño responsive
La interfaz está preparada para adaptarse a distintos tamaños de pantalla. Se debe comprobar su visualización y funcionamiento en navegadores de escritorio y dispositivos móviles.
