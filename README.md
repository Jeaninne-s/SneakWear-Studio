SneakWear Studio
SneakWear Studio es una plataforma web responsive orientada a la exploración, personalización y compra de zapatillas. El proyecto busca ofrecer una experiencia digital sencilla e interactiva para que los usuarios puedan configurar un diseño, revisar sus características y consultar el estado de un pedido.

Este proyecto fue desarrollado como parte del curso HCI for UX Design.
Funcionalidades principales
- Exploración de modelos y acceso a la comunidad de diseños.
- Personalización de zapatillas mediante selección de colores y materiales.
- Selección de talla y consulta de una guía de medidas.
- Vista previa interactiva del diseño, con controles de rotación.
- Incorporación de texto y opciones adicionales de personalización.
- Guardado de diseños, favoritos y borradores en el navegador.
- Carrito de compras y resumen de la configuración seleccionada.
- Validación de disponibilidad de tallas antes de continuar con la compra.
- Consulta de reseñas y valoraciones de productos.
- Visualización de las etapas de seguimiento del pedido.
Nota: Esta entrega es un prototipo front-end académico. Algunas operaciones, como el stock, el pago y el seguimiento, utilizan datos de demostración y no representan transacciones ni servicios comerciales reales.

Tecnologías utilizadas
- HTML5: estructura y contenido de la página.
- CSS3: estilos, diseño visual y adaptación responsive.
- JavaScript: interacciones y comportamiento de los componentes.
- LocalStorage: almacenamiento local de determinados datos del usuario en el navegador.

Ejecución local
1. Descarga o clona este repositorio.
2. Mantén los archivos y la imagen dentro de la misma estructura de carpetas.
3. Abre el archivo index.html en un navegador actualizado.
No se requiere un proceso de compilación para ejecutar esta versión estática.
Publicación en GitHub Pages
Para publicar el proyecto mediante GitHub Pages:
1. Ingresa al repositorio en GitHub.
2. Abre Settings y selecciona Pages.
3. En Build and deployment, selecciona Deploy from a branch.
4. Elige la rama principal (main) y la carpeta raíz (/root).
5. Guarda los cambios y espera a que GitHub Pages genere la URL pública.
La página publicada debe probarse tanto en escritorio como en dispositivos móviles.
Equipo y propósito académico
Proyecto desarrollado por el Grupo 3 para el curso HCI for UX Design. Su objetivo es aplicar principios de diseño centrado en el usuario, arquitectura de información, interacción y validación de experiencia de usuario a una plataforma de personalización de zapatillas.
